## 🚀 How to Host
1. Fork or clone this repository.  
2. Go to **Settings → Pages**.  
3. Under **Branch**, select `main` and root (`/`).  
4. Click **Save** — your site will be live in a few seconds!

---

## 📷 Customization

- Edit the main heading or quotes in `index.html`.
